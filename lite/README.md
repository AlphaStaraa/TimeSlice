# 时刃 Lite · TimeSlice Lite

当前为1.0.8 Lite，保留RGB10/PQ/HLG预览修复，并使用流式HDR峰值扫描；共享导出模块对Windows大只读源使用有界文件读取，见[内存优化](../docs/HDR内存优化_1.0.8.md)。支持推荐/自定义1–500 Mbps码率与默认开启的平滑渐变。以下1.0.4性能数据是历史验证，画质规格见[导出画质](../docs/导出画质_1.0.5.md)。

AlphaStar · 完全免费开源 · AGPL-3.0-only。

导入已经制作好的延时视频，选择切片并调整参数，选择保存位置后导出。默认单选；需要多种效果时开启多选，拖动队列决定分别导出的顺序。

包含46种效果/35个形状入口、冻结与昼夜分割、旋转起始角度、单侧阴影、时间图与输入区间。冻结默认60切，阴影强度25%、宽度50%；其他效果阴影默认关闭。示例视频可在空白页直接试用。

轻量版提供视频切片流程；完整版另提供视频稳定、去闪和风格调色。输出可选H.264 8位SDR、HEVC10 SDR、HDR PQ和HDR HLG；原生HDR输入可保留亮度，主预览采用SDR映射。

第一次导出前自行选择位置。自动选择GPU合成与可用硬件编码，必要时回退CPU。正式源解码缓存可在同次会话复用，改变切片/阴影不重复解码；改变视频、输出尺寸或时间精度会准备对应缓存。退出清理工作缓存，原片保留。

短源在Mac设备预算允许时复用GPU源分块，减少重复上传。额外显存预算最多2GiB，同时受Metal推荐工作集的1/16及可用主存的1/8限制。

1.0.4针对长源增加按空间块渲染、按时间组暂存的路径，避免反复整理和上传整段原片。只有预计收益明显且工作盘空间足够时启用；系统缓存盘空间不足时会检查用户已选的输出盘。分辨率、帧率、时间采样和效果公式保持原样。

完整精度的20秒4K60源解码缓存约39.8GB；优化路径的20秒成片暂存另约39.8GB，逐组最多读取256MiB。临时成片在完成或取消后删除；源解码缓存为再次导出保留到换素材或退出。实际耗时、测试边界和缓存规则见[验证记录](../docs/Lite_1.0.4_验证.md)，不保证所有素材、硬盘或显卡同幅度提速。

参数可从右上角菜单保存/导入JSON。文件不包含视频路径、输出位置或外部时间图。本地统计默认关闭；只有主动开启才记录结果、效果编号与耗时，用户自行导出，不自动上传。

## 构建与验证

macOS14+、Apple Silicon；本机实际验证平台见随交付的验证记录。源码对应配置、第三方归档与许可在lite/vendor。编译需Xcode Command Line Tools；首次构建会在项目内编译固定视频工具。使用系统字体，不打包独立字体。

```sh
python -m pip install -r lite/requirements-build.txt
make lite PYTHON=python
python tools/check_lite.py
python tools/golden.py --stage build/lite/stage/app
python tools/benchmark.py --repeats 3
```

`python tools/check_lite_render.py`需要真实GPU，验证全部效果常驻/分块像素及异常释放。4K交替对照可运行 `python tools/profile_lite_4k.py --mode compare --source /path/to/4k60.mp4 --output build/lite/profile-4k --repeats 3`；需提供3840×2160素材，固定输出三种效果各1秒。此耗时不包含随后独立解码检查。

FFmpeg精简构建从随附源码编译，保留H.264/HEVC、常用视频容器及必要音频、缩放、帧率转换，包含VideoToolbox和libx264回退。其GPL与第三方许可随软件保留。切片内核与完整版同源。

包内显式`--self-check 输出目录 --require-gpu`只用于自动验收，使用独立设置与缓存。正常打开即可使用主工作台。软件按原样提供，使用者应备份素材并自行检查成片；完整条款见LICENSE。

1.0.6支持真正的HEVC10 SDR、PQ与HLG，详情见[HDR与十位输出](../docs/HDR与十位输出_1.0.6.md)。
