# Mac 5.2 的算法与验证

固定机位稳定采用多参考图、归一化细节特征与 RANSAC 相似变换。较大明暗变化时可用 SIFT 特征匹配作为补充。极致档再以 OpenCV ECC 做亚像素精修，并用未参与拟合的固定点检查是否改善。整段统一裁切，短缺测区间插值变换，保留原帧。

OpenCV 的图像配准及 ECC 接口说明 https://docs.opencv.org/4.x/dc/d6b/group__video__track.html

VidStab 的开源全局运动估计流程也是本轮调研参考之一，采用 MIT 许可。本版运行时使用项目已有的 OpenCV 组件与自有固定机位实现。https://github.com/AdamSpannbauer/python_video_stab

去闪先测量对齐后的分块对数亮度，稳健估计公共曝光变化，再用鲁棒二阶曲线平滑求出逐帧补偿。三个档位调整平滑尺度和补偿范围，极致档再平滑小幅中性色彩跳动。这个方法修正原帧的亮度与颜色，不混合相邻视频帧。FFmpeg 的时间亮度统计去闪实现可作基础方法参考。https://github.com/FFmpeg/FFmpeg/blob/master/libavfilter/vf_deflicker.c

调色在切片之前应用，首尾色温、色调、饱和度、曝光与对比度沿原片时间平滑变化。自动曲线结合低频亮度进程与时间进程，保留首尾端点。默认用温暖的日景与偏冷青的夜景形成对比；压缩视频的白平衡调整采用相对值。

Adobe 对 Temp、Tint、Saturation 和 Color Grading 的说明 https://helpx.adobe.com/lightroom/web/edit-photos/apply-effects/adjust-color.html

LRTimelapse 作者关于关键帧、日夜过渡及多次去闪的官方教程 https://gwegner.de/know-how/zeitraffer-ltimelapse-5-tutorial-deutsch/

两层切片先生成保持冻结几何的流动纹理，再让第二层时间场取样这段纹理。第二层起始从冻结完成帧开始，并平滑展开时间跨度。CPU 与 Metal 使用相同的阶段分配，时间图也显示合成后的取样关系。

已知抖动测试使用 384×256 合成固定场景，加入约 1.8 像素平移、轻微旋转、自然变暗与曝光闪动。固定点残差 P95 约 0.15 像素。三档去闪的帧间跳变 P95 从约 0.39 EV 分别降至约 0.048 / 0.035 / 0.030 EV。这些数值只描述该测试序列。

上海中心测试使用长边 480 像素、3fps 的全时段代理，识别为日转夜。处理保留全部 60 个代理帧。原片已经较稳定，固定点残差 P95 约 0.065 像素。该代理验证不代表任意 4K 素材都会得到同样数值。

稳定、去闪及调色缓存只写入应用自己的临时目录，原始视频 保留原样。调色和稳定改变的画面可在“素材”预览中检查，关闭相关选项可恢复相应输入处理。
