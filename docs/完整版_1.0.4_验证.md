# 时刃1.0.4视频切片版

2026-11-15，AlphaStar，免费开源、AGPL-3.0-only。

## 当前工作流

导入延时视频 → 选择和调整切片 → 选择保存目录 → 按队列分别导出。

本次从界面、任务控制器、后台实现、移动端原生库、依赖和构建脚本中移除照片序列及一键合成管线。删除桌面向导、文件夹拖入分支、移动端素材类型选择、一键菜单、合成阶段与微闪选项；视频导入直接使用系统视频选择器。

保留全部46种切片、时间图、昼夜分割、默认60切及25%/50%阴影。完整版保留视频稳定、三级去闪、首尾调色/HSL、处理进度/预计时间和缓存复用；Lite专注切片输出。切片参数JSON的保存和导入继续作为视频参数管理功能提供。

已保留上一轮修复：奇数宽度扇形/扇形波纹中心轴、统一桌面玻璃弹窗圆角、安卓浅深外观及关于页、中英文许可和第三方声明。安卓法律资源使用稳定ASCII文件名，并在签名前检查真实APK内容，不能仅检查源码目录。
