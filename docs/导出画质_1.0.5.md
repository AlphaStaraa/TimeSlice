# 1.0.5 导出画质更新

Mac完整版、Mac Lite、Windows共享1.0.5源码；Android独立版本为1.0.4-quality-preview.1（build104）。作者AlphaStar，AGPL-3.0-only，免费提供。

## 改动

- 输出页提供“推荐 / 自定义”码率，自定义范围1–500 Mbps，支持小数。推荐按实际输出像素与帧率计算，横竖屏一致；1080p30/60约20/35 Mbps，4K30/60约60/100 Mbps。
- Mac不再固定20 Mbps；Windows VideoToolbox以外的NVENC、QSV、AMF及CPU x264也接收同一目标。手机的负载检查、界面摘要和编码配置使用同一套规则。
- 高级选项新增“平滑渐变”，默认开启。在插值/调色/阴影完成后的8位量化处使用固定8×8亚色阶抖动；偏移小于半个8位色阶，锚定画面位置，不产生逐帧随机闪烁。整数原像素测试保持一致。可以关闭。
- RGB到YUV明确采用Rec.709有限范围、精确舍入与误差扩散配置，输出仍为8位SDR H.264。不是10位/HDR或恢复已经丢失的颜色。
- 修改码率不会重建源缓存或重算预览；批量导出统一使用选定目标。渲染记录单独保存目标码率，VBR实际码率随内容、片长和编码器变化。
- 手机不支持某个自定义目标时明确报错，不静默降码率；兼容软件兜底编码不承诺可指定码率。

## 真实4K60编码对照

使用真实20秒《大连20》源、24个时间样本生成同一段1秒4K60合成帧，再分别编码。三份视频均完整解码60帧；以下PSNR针对第0、30、59帧与相同编码前RGBA的RGB误差，不是完整影片平均值。

| 目标设置 | 整体PSNR | 天空区域PSNR |
| --- | ---: | ---: |
| 原版固定20 Mbps | 30.37 dB | 38.31 dB |
| 新版推荐100 Mbps | 34.01 dB | 42.76 dB |
| 新版自定义150 Mbps | 35.65 dB | 44.29 dB |

PSNR越高代表本次对照中压缩误差越小；不等同于所有素材均有固定提升。1秒VBR文件可能明显偏离目标码率。这里只比较编码质量，不把1秒对照片段当成完整20秒性能基准。
