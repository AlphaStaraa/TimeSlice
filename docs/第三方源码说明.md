# 第三方源码与构建来源

项目自有代码的AGPL与第三方组件的许可证分别适用。实际二进制内的LICENSE/COPYING/NOTICE须随平台包保留；本文件用于定位构建来源，不把上游许可改写成AGPL。

| 组件 | 固定来源/对应文件 |
| --- | --- |
| Mac FFmpeg9.0.2 | `lite/vendor/ffmpeg-9.0.2.tar.xz`；SHA和来源见`lite/vendor/build.json`及`mac-5.0-redesign/full-ffmpeg-source.json` |
| x264 / pkgconf | 对应源码归档随`lite/vendor/`提供，来源/SHA见同目录`build.json` |
| dav1d1.5.1 | `mac-5.0-redesign/vendor/dav1d-1.5.1.tar.bz2`及同目录上级`full-ffmpeg-source.json` |
| 精简OpenCV4.13.0 | 官方完整源码URL与SHA见`mac-5.0-redesign/compact-opencv.json`，Apache许可见`LICENSES/OpenCV-4.13.0.txt` |
| Windows FFmpeg9.0.2 | Gyan essentials静态GPLv3构建，由imageio-ffmpeg提供；实际exe已与上游清单SHA256核对，见`windows-ffmpeg-provenance.json` |
| Qt/PySide6 | 版本锁在`requirements.txt`，对应源码位于[Qt源码镜像](https://download.qt.io/official_releases/qt/)与[PySide源码仓库](https://code.qt.io/pyside/pyside-setup.git/)，按所用版本查找 |
| Android OpenCV/JCodec | 版本、Maven地址、SHA256及许可位置见`mobile/dependencies.json`；[OpenCV源码](https://github.com/opencv/opencv/tree/4.13.0)、[JCodec源码](https://github.com/jcodec/jcodec/tree/v0.2.5) |
| 其他运行时 | 版本锁、上游及许可见`requirements.txt`与`THIRD_PARTY.md`；随平台包保留其原始许可证 |

Mac裁剪构建脚本为`tools/build_full_ffmpeg.py`、`tools/build_lite_ffmpeg.py`和`tools/build_compact_opencv.py`。固定归档构建参数用`${PROJECT_ROOT}`表示本机项目根，不含作者个人目录。

Windows预览沿用上游Gyan构建，编译选项含静态第三方库；FFmpeg主源码位于[FFmpeg9.0.2](https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz)，构建来源见[Gyan构建站](https://www.gyan.dev/ffmpeg/builds/)与[镜像](https://github.com/GyanD/codexffmpeg)。Windows第三方源码说明须与实际配置一起提供，不能将Mac的裁剪配置冒充Windows配置。发布者仍需按具体构建核对静态依赖、对应源码取得方式与许可证义务。

从干净仓库构建的CI预览使用当前依赖源；它们可能与本地经过实机验收的裁剪包体积不同。CI预览不是已完成全部实机验证的正式构建。安卓CI调试APK使用临时调试签名，不能作为用户已安装官方预览版的同签名更新。
