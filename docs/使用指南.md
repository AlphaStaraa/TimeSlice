# 使用指南

作者 AlphaStar。当前Mac完整版与Lite为1.0.5测试版，Windows为1.0.5画质预览，Android为1.0.4画质预览。各平台独立标号。

## 平台

- Mac：macOS 14+、Apple Silicon，打开独立“时刃.app”。
- Windows：Windows 10 22H2 / 11 x64；先完整解压，再打开“时刃.exe”。显卡兼容问题可使用包内“CPU兼容模式.cmd”。
- Android：Android 10+，ARM64 / x86_64。手机可用的分辨率、帧率、编码器组合由设备能力决定。

## 流程

1. 导入一段延时视频。
2. 在左侧效果库选择效果；横屏素材的已选队列位于预览下方，竖屏位于侧边，可拖动排序。
3. 在素材页按需开启固定机位稳定、轻/中/强三级去闪。处理会立即开始并显示进度和预计时间；完成的正式源缓存供导出复用。修改调色或 HSL 只更新合成配置。
4. 冻结默认 60 切，阴影开启；其他效果阴影默认关闭。阴影强度 25%、宽度 50%，可以调整或反向。
5. 昼夜分割默认跳过素材中间 60%。未冻结底片连续播放，只有冻结切片取首尾；最后一片展开完成即结束。
6. 设置导出规格。首次导出先自行选择输出目录，之后按队列顺序分别导出各效果。可查看进度、预计剩余时间，并安全取消。

固定机位稳定受特征匹配、视差和可用裁切影响，无法对所有素材保证零抖动。手机正式素材缓存上限 2GB，需要时缩短素材或减少时间样本。

Android 高分辨率、高帧率或高码率导出前会提醒性能、耗电与发热；高热状态会降速，临界温度停止并保留已完成文件，不擅自改变输出规格。

Mac完整版与Lite在同一次打开软件期间保留一份可复用的视频解码缓存。修改切片后再次导出可复用；完整版修改调色也可复用。换素材、改变源处理条件或退出软件会清理。4K完整采样仍需要较多工作盘空间。

## 导出画质

输出页提供推荐与自定义码率，自定义范围1–500 Mbps。推荐值按实际输出像素和帧率计算：1080p30/60约20/35 Mbps，4K30/60约60/100 Mbps，横竖屏一致。VBR是目标码率，实际码率随画面内容、片长与编码器变化。

“平滑渐变”默认开启，可在高级选项关闭。它在最终8位合成量化时使用固定的亚色阶抖动，降低插值、调色和阴影新增的色带；不是去闪、模糊或10位输出，也不能修复原片已经丢失的颜色。高码率需要更多磁盘空间。
