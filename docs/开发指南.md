# 开发指南

## 目录与唯一来源

| 目录 | 责任 |
| --- | --- |
| app/ | 共用时间场、CPU/GPU 引擎、媒体、模型及桌面基础控制器 |
| mac-5.0-redesign/ | Mac/Windows 共用的当前 UI、桌面控制器、源处理、导出与桌面着色器 |
| mobile/android/、android-core/、shared/ | Android 界面、JNI、共享协议与移动内核 |
| tools/、mobile/tools/ | 当前构建、验证与源码导出入口 |
| tests/ | 无需用户素材的数值测试，以及桌面专项回归脚本 |
| docs/ | 当前使用、维护及验证文档 |
| assets/、LICENSES/ | 必需预览、图标、许可 |

历史代码不参与当前构建；本仓库只维护一个桌面实现。build/、dist/、.venv/、SDK/NDK 和签名密钥是本地依赖或产物，由忽略规则和源码导出白名单排除，不应提交。

## 控制器职责

基础层依次为 controller_state → controller_media → controller_preview → controller；桌面层依次为 mac_controller → source_controller → preview_controller → next_controller。QObject 的属性、信号、Slot 保留在真正的 QObject 继承链中，避免普通 mixin 导致 Qt 元对象丢失。next_controller 保留独立 uiChanged 信号，不覆盖父类 NOTIFY。

效果列表与默认值在 effect_models，准备缓存的导出任务在 processed_render；源码整理不修改时间场和阴影公式。prepare_desktop 自动覆盖桌面顶层模块，新增模块不会因手写打包清单而遗漏。

## 构建

Python 3.11+，先运行 `python -m pip install -r requirements-dev.txt`。代码规范固定 Ruff 0.17.5，100 列；启用 E4、E5（含 E501）、E7、F、I。少数必须引导 sys.path 的旧测试仅豁免 E402，不豁免行长或分号规则。

Mac 安装 Xcode Command Line Tools；Windows 安装 Visual Studio C++ Build Tools，在 Developer PowerShell 执行构建。

```sh
make check PYTHON=python
make test PYTHON=python
make desktop PYTHON=python
```

无 Make 时直接执行：

```sh
python -m ruff format --check .
python -m ruff check .
python tools/verify_source.py
python tools/check_desktop.py --cpu-only
python tools/check_desktop.py --gpu
python tools/build_desktop.py --package
```

CPU 测试会从当前源码编译临时内核；Linux 编译入口仅供 CI，不代表发布 Linux 产品。--gpu 必须有真实可用的 WGPU 适配器，失败不能静默当作 CPU 通过。

Mac精简完整版依赖可选构建如下。精简FFmpeg的全部构建归档已随源码提供；精简OpenCV原始归档按锁文件的地址取得并核对SHA256。两个构建均在项目build目录隔离，不覆盖开发环境或Windows依赖。未完成可选构建时，普通打包使用官方依赖。

```sh
python -m pip install -r requirements-compact-build.txt
python tools/build_full_ffmpeg.py
python tools/build_compact_opencv.py --archive /path/to/opencv-4.13.0.tar.gz
python tools/build_desktop.py --package
```

独立完整版支持显式验收：`时刃.app/Contents/MacOS/时刃 --self-check /tmp/timeslice-check --self-check-source tests/benchmark/source.mp4 --require-gpu`。它隔离偏好与缓存，验证稳定/去闪、HSL、加工缓存和未加工视频会话缓存，输出报告后正常退出；不向正常界面增加测试入口。

Android：先 `python mobile/tools/sync_android_stable.py`；安装 JDK 17+ 和 Gradle 8.13，执行 `gradle -p mobile/android assembleDebug`，或 `make android`。手工打包脚本主要用于当前本机缓存环境；CI 使用 Gradle 标准入口。正式更新应保留自己的签名密钥。

GPU 生成文件已随源码附带；修改内核后，设置 SLANGC 并运行 `mac-5.0-redesign/build_next_shaders.py` 及 Android 同步脚本。统一入口 tools/build_open_shaders.py 只生成当前桌面与 Android 着色器。

## 源码交付

`make source` 输出干净目录 `dist/TimeSlice-source`。导出器只收纳维护中的源码、测试、文档和资源；目的目录存在时必须为空，避免旧文件混入。签名密钥、用户素材和临时测试视频不在源码包内。GitHub Actions 提供格式、源码一致性和 Mac/Windows/Linux CPU 测试，运行结果以实际工作流为准。
