# 验证矩阵

当前候选：Mac完整版/Lite与Windows 1.0.5、Android 1.0.4画质预览。当前只接收延时视频，各平台独立维护版本。

| 范围 | 本版结果 | 边界 |
| --- | --- | --- |
| 核心与编码 | 23项CPU/Metal/真实编码回归，46效果92标准帧 | 本机M1 Max；不泛化所有显卡 |
| Mac完整版 | 实际App以原20秒上海源检查稳定、去闪、HSL、缓存与短片解码；QML警告0 | 功能自检采用384长边；不是全20秒4K性能测试 |
| Mac Lite | 真实控件、自定义73.5 Mbps、单多选/队列、缓存、GPU与独立App导出 | 不提供稳定/去闪/调色面板 |
| 渐变与分块 | 开/关分别验证常驻、分块、空间顺序504帧及长时间线索引 | 亚色阶抖动不能修复源素材色带，也不等于10位输出 |
| 真实4K60编码 | 大连20秒源、24样本、1秒60帧，原20/新100/自定义150 Mbps对照与完整解码 | 编码质量对照，非全片性能基准 |
| Android | 红米真机中英浅深/许可全文/手动控件/实际导出；另测1080p30与4K60的推荐/自定义目标 | 24源样本、短片验证；GPU时间场+CPU合成，不宣称全GPU或全20秒手机性能 |
| Windows | 新源码、共享Qt界面、x64交叉构建与现有嵌入式运行时 | **本轮待Windows实机验证**；用户已选择先交付并标注。1.0.4的历史实机通过不代表1.0.5通过 |
| GitHub CI | 保留上轮已修复的Linux/SDK/浮点abs/路径测试配置 | **本版尚未推送运行云端CI** |

详细方法与质量对照见[导出画质1.0.5](导出画质_1.0.5.md)。原始素材保持不变，安装包与源码使用SHA256校验。
