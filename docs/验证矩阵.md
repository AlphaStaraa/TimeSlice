当前候选为桌面1.0.6、Android1.0.5 HDR预览，只接收视频。细节见[HDR与十位输出](HDR与十位输出_1.0.6.md)。

| 范围 | 已验证 | 边界 |
| --- | --- | --- |
| 原效果与8位兼容 | 46效果92标准帧，原PNG SHA保持一致；手动码率、队列与解码回归 | 不放宽标准帧门槛 |
| 高精度内核 | 29项CPU/Metal/编码回归，1024级渐变、PQ绝对亮度、HLG、HDR曝光与高精度去闪 | M1 Max；不泛化所有显卡 |

| Windows | 新176字节参数ABI与x64原生DLL/启动器交叉构建 | **本轮待实机验证**，旧版结果不代表本版通过 |
