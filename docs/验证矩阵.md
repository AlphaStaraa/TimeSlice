# 视频切片版验证矩阵

当前只接收延时视频。Mac完整版1.0.4、Mac Lite1.0.4、Android1.0.3视频切片预览、Windows1.0.4视频切片预览分别维护版本。

| 范围 | 已验证 | 边界 |
| --- | --- | --- |
| 切片内核 | 46种效果、92标准帧；20项CPU/Metal回归，含奇数预览中心轴和已移除任务接口检查 | 本机M1 Max；不代表所有显卡 |
| Mac完整版 | 原20秒上海4K60视频；稳定、去闪、HSL、两类缓存、三段短片完整解码；实际应用签名 | 功能验收用384长边，不当作完整4K性能数据 |
| Mac Lite | 单多选、队列、参数JSON、缓存、实际编码解码、发布基准门禁 | 无视频稳定/去闪/调色处理面板 |
| 桌面界面 | 关于、错误、退出弹窗，中英文与浅深外观；顶部和空白状态只提供视频入口 | 验证详见本版本记录 |
| Android | 视频专注版真机40个界面状态、许可全文/第三方说明、实际导出12帧完整解码，确认专用类与一键入口不存在 | 真实20秒4K60源，24源样本、1280长边UI/短片验收；源缓存2GB限制仍在 |
| Windows | 独立Win实机默认窗口、视频处理/HSL/缓存自检、92标准帧与92CPU-GPU、6段1080p、2类取消清理及8组奇数扇形预览通过；错误弹窗950次更新不重开 | 授权同一用户Windows对话回报，原最终转发ZIP未在Win解压，不泛化所有显卡 |

用户原始视频保持不变，测试使用独立缓存。本地历史验证文档已移到维护记录，不作为当前功能清单；GitHub仍未发布。
